## B. Niche scoring matrix

List 3–5 candidate niches. Score each 1–5 on every criterion. **Pick the highest total ≥ 32.** If none clears 32, narrow the niche (add an audience or an angle) and score it again.

| Criterion | Question | Weight |
|---|---|---|
| **Demand** | Do 3+ small channels (<50k subs) in the niche get videos with views > 5× their subscriber count? | ×1 |
| **Advertiser value (RPM)** | Do advertisers pay to reach this viewer? (finance, software, business, education, tech = high; entertainment, gaming, kids = low) | ×1 |
| **Monetization beyond ads** | Is there an obvious product, affiliate, or service to sell this viewer? | ×1 |
| **Sustainability** | Could you make 100 videos on this without hating it? | ×2 |
| **Edge** | Do you have expertise, access, a perspective, or a production skill that competitors lack? | ×2 |
| **Competition gap** | Are the top channels stale, generic, too advanced, too basic, or ignoring a sub-audience? | ×1 |
| **Production fit** | Can you make it with your current hours, gear and skills? | ×1 |

Max score = 45. Template:

| Niche candidate | Demand | RPM | Beyond-ads | Sustain ×2 | Edge ×2 | Gap | Fit | **Total** |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |
| | | | | | | | | |
| | | | | | | | | |

### Niche narrowing formula
`[Broad topic] for [specific person] who wants [specific outcome] [constraint/angle]`

- ❌ "Fitness"
- ✅ "Strength training for desk workers over 35 with 30 minutes and no gym"

The narrower version is easier to rank, to recommend, to remember and to monetize. You can widen later. Widening is easy once you have an audience; narrowing after launch is painful.

**Sourcing real language (do this, don't guess):**
1. Sort the comments on your top 5 competitors' best videos by "Top". Copy the questions and complaints.
2. Search Reddit/forums for `[niche] + "I wish" / "struggling" / "how do I"`.
3. Type your topic into YouTube search and note the autocomplete suggestions for each letter (`topic a…`, `topic b…`).

## D. Competitor map

Find **10 channels**: 3 large (>500k), 4 mid (50k–500k), 3 small (<50k but growing). Small, fast-growing channels are your best teachers because what worked for them is closer to what works at your size.

| Channel | Subs | Uploads/wk | Top-performing format | Avg views (last 10) | Outlier videos (>3× avg) | Weakness / gap |
|---|---|---|---|---|---|---|
| | | | | | | |

**Outlier method:** For each channel, sort by Popular. Any video with 3×+ the channel's normal views is a **proven topic**. Put every outlier in your idea bank, then make *your* version of it: a different angle, better or more current, for your specific viewer. Never copy.
